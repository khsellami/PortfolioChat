# PortfolioChat

PortfolioChat is a web-based portfolio and chatbot application designed to showcase your professional profile and allow visitors to interact with a chatbot for information, resume download, and contact options.

## Features

- **Chatbot Interface:** Users can chat with an AI-powered bot to ask questions about your experience, skills, and projects.
- **Resume Download:** Visitors can download your resume directly from the site.
- **Contact Links:** Quick access to your email, LinkedIn, GitHub, Instagram, Telegram, and WhatsApp.
- **Modern UI:** Responsive design with attractive visuals and smooth user experience.
- **Sound Notification:** Plays a sound when a message is sent.

## Getting Started

1. **Clone the repository:**
   ```powershell
   git clone https://github.com/yourusername/PortfolioChat.git
   ```
2. **Open `index.html` in your browser.**
3. **Customize:**
   - Replace the resume PDF in `assets/` with your own.
   - Update profile images and social links in `images/` and `index.html`.
   - Edit chatbot logic in `script.js` as needed.

## Customization

- **Profile Details:** Update your name, profile picture, and contact info in `index.html`.
- **Chatbot Responses:** Modify or extend chatbot logic in `script.js`.
- **Styling:** Change colors, fonts, and layout in `style.css`.

## Dependencies

This project uses only vanilla HTML, CSS, and JavaScript. No external dependencies are required.
